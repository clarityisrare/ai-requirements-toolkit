# Worked Examples

The rest of the toolkit gives you the tools. This folder shows them **in action** — real
before/after transformations and sample AI outputs, so you can see what "good" looks like
before you try it on your own work.

| Example | Shows |
|---|---|
| [Vague vs clear requirement](./vague-vs-clear-requirement.md) | The same requirement rewritten from ambiguous to testable, with the reasoning |
| [Document upload — worked example](./document-upload-worked-example.md) | Taking a one-line ask through the Document Upload pattern to full requirements and criteria |
| [AI review — sample output](./ai-review-sample-output.md) | What the AI Review prompts actually return, as a findings table |

> These are illustrative examples, not real project data. Use them as a reference for format
> and depth, then ground your own work in your stakeholders' input.
