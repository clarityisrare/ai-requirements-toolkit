# Requirement Quality Review

## Completeness

- [ ] Actor identified
- [ ] Trigger identified
- [ ] Expected outcome defined

## Clarity

- [ ] No vague or subjective term left undefined — any adjective whose truth cannot
      be settled by a measurement (e.g. "fast", "secure", "easy", "appropriate",
      "flexible") belongs in this set
- [ ] Any remaining subjective term has a measurable definition

## Testability

- [ ] Acceptance criteria exist
- [ ] Success condition measurable

## Consistency

- [ ] No contradiction
- [ ] Uses glossary terms

## Traceability

- [ ] Source identified
- [ ] Linked to business objective

## AI Readiness

- [ ] Source provided
- [ ] Context provided
- [ ] Constraints stated
