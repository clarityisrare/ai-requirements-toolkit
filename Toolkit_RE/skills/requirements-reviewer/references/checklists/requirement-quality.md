# Requirement Quality Review

## Completeness

- [ ] Actor identified
- [ ] Trigger identified
- [ ] Expected outcome defined

## Clarity

- [ ] No vague or subjective terms left undefined — run the requirement through the
      [Ambiguity Detector prompt](../ambiguity-detector.md) to catch the full set
- [ ] Any remaining subjective term has a measurable definition

## Testability

- [ ] Acceptance criteria exist
- [ ] Success condition measurable

## Consistency

- [ ] No contradiction
- [ ] Uses glossary terms

## Traceability

- [ ] Source identified
- [ ] Linked to business objective

## AI Readiness

- [ ] Source provided
- [ ] Context provided
- [ ] Constraints stated
