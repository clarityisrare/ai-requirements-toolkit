# Output Quality Gate

Run against `40-response.md` before delivery. The ID audit is the one that
catches the most.

## The ID audit
- [ ] Every material statement is attributable to an upstream finding ID
- [ ] Every ID cited exists in the file it claims to come from — verified by
      reading, not by memory
- [ ] Nothing was introduced that no upstream stage produced

## Preservation
- [ ] Every `CONFLICT_REQUIRES_REVIEW` appears, still unresolved
- [ ] Every evidence gap appears
- [ ] Every localisation requirement appears (if convergence ran)
- [ ] Residual fragmentation appears (if convergence ran)
- [ ] Every ambiguity material to the answer appears
- [ ] Comparison classifications unchanged — same labels, not softened paraphrase
- [ ] Convergence classifications unchanged

## Separation
- [ ] Swiss and EU findings in separate sections
- [ ] Source lists separated by jurisdiction
- [ ] Every statement traceable to one regulator
- [ ] Interpretation still labelled as interpretation

## Confidence
- [ ] All four dimensions assessed, or marked `N/A` where the stage did not run
- [ ] Each dimension has a rationale
- [ ] Overall is the floor of the applicable dimensions, or the upward departure
      is stated and justified

## Boundaries
- [ ] No recommendation, instruction, or "the firm should…" phrasing
- [ ] No new regulatory conclusion
- [ ] No conflict resolved
- [ ] No gap closed by reasoning
- [ ] No legal advice

## Mechanics
- [ ] Structure matches the question type
- [ ] Traceability appendix present and complete
- [ ] Standard footer present, with as-of date, grounding mode and run directory
- [ ] The question actually asked has been answered
