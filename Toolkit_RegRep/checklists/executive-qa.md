# Executive Brief Quality Gate

Run against `50-executive.md`.

## The compression test
- [ ] Nothing material was dropped for readability
- [ ] Every unresolved conflict is visible
- [ ] Every evidence gap is visible
- [ ] Every localisation requirement is visible
- [ ] `LOW` confidence is still reported as `LOW`
- [ ] No difficult finding has been rounded toward a comfortable one

## Inheritance
- [ ] Confidence copied verbatim from `40-response.md` — not re-scored
- [ ] Priorities derive from upstream materiality, with the driver stated
- [ ] Risk ratings appear only where upstream supports them
- [ ] Residual fragmentation, if reported, comes from the convergence file

## Fitness for audience
- [ ] Bottom line is 3–5 sentences or five bullets, and is actionable alone
- [ ] The page fits on a page
- [ ] Decisions and attention required is substantive, not a stub
- [ ] Only appendices the run actually produced are included
- [ ] Plain business language; no citations in the body, no legal drafting, no
      implementation detail

## Boundaries
- [ ] No recommendation or course of action
- [ ] No new conclusion, interpretation, or regulatory statement
- [ ] No conflict resolved
- [ ] Standard footer present

## The final question
- [ ] Could an executive act on this and be acting on what the evidence actually
      supports?
